Icon badges used by the Technical Skills and Portfolio sections.
- skills/     one icon per tool, referenced from PORTFOLIO_DATA.skillCategories
- portfolio/  one icon per portfolio category, referenced from PORTFOLIO_DATA.portfolioCategories
These are original monogram-style placeholder badges (not brand logos) — swap in
your own icon files any time by replacing the file at the same path, or by
changing the "img" path in PORTFOLIO_DATA. No HTML/CSS edits required either way.
